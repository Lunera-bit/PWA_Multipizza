✅ PÁGINA DE DELIVERY (/delivery-pedidos)

   • Ver pedidos aceptados
   • Marcar como entregado

✅ PÁGINA DE TRACKING (/order-tracking/:orderId)
   • Mapa interactivo con Mapbox
   • Ubicación en tiempo real del delivery
   • Distancia calculada automáticamente
   • Tiempo estimado de entrega
   • Información del repartidor (nombre, foto, teléfono)
   • Botón para llamar
   • Detalles completos del pedido

✅ SERVICIO DE TRACKING
   • Obtención de ubicación GPS
   • Seguimiento continuo (cada 10 segundos)
   • Cálculo de distancia (Fórmula Haversine)
   • Estimación de tiempo
   • Listeners en tiempo real

  🚀 3 PASOS PARA EMPEZAR
═══════════════════════════════════════════════════════════════════════════════════════

1️⃣  CONFIGURAR MAPBOX TOKEN
    • Abre: src/app/pages/order-tracking/order-tracking.page.ts (línea ~240)
    • Reemplaza: 'tu_token_aqui' con tu token de Mapbox
    • Obtén en: https://www.mapbox.com/

2️⃣  CREAR USUARIO DELIVERY
    • Firebase Console → usuarios collection
    • Nuevo documento con: { rol: "delivery", displayName: "...", ... }

3️⃣  PROBAR LOCALMENTE
    • npm install
    • ionic serve
    • Accede a: http://localhost:8100/delivery-pedidos
