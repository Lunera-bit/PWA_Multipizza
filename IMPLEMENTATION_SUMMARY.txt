═══════════════════════════════════════════════════════════════════════════════════════
  🎯 FLUJO DE PEDIDOS
═══════════════════════════════════════════════════════════════════════════════════════

CLIENTE CREA PEDIDO
        ↓
        ├─ Status: "pendiente"
        ├─ Sin delivery asignado
        └─ Visible en lista de available
        
        ↓
        
DELIVERY ACEPTA PEDIDO
        ├─ Se inicia geolocalización (cada 10s)
        ├─ Status: "en camino"
        ├─ Se asigna deliveryPerson
        └─ Se actualiza Firestore
        
        ↓
        
CLIENTE VE TRACKING
        ├─ Accede a /order-tracking/{orderId}
        ├─ Ve mapa con ubicación real
        ├─ Ve distancia y tiempo estimado
        ├─ Ve info del repartidor
        └─ Puede llamar
        
        ↓
        
DELIVERY ENTREGA
        ├─ Clic "Marcar Entregado"
        ├─ Status: "entregado"
        ├─ Geolocalización se detiene
        └─ Pedido completado

  🔌 TECNOLOGÍAS INTEGRADAS
═══════════════════════════════════════════════════════════════════════════════════════

Frontend:           Angular 20 + Ionic 8 (Standalone Components)
Base de Datos:      Firebase Firestore (Realtime)
Autenticación:      Firebase Authentication
Geolocalización:    Capacitor Geolocation
Mapas:              Mapbox GL JS v3.5.0
Cálculos:           Fórmula Haversine (distancia GPS)
Lenguaje:           TypeScript 5.8

  ⚙️ CONFIGURACIÓN REQUERIDA
═══════════════════════════════════════════════════════════════════════════════════════

1. MAPBOX TOKEN
   Archivo: src/app/pages/order-tracking/order-tracking.page.ts (línea ~240)
   ❌ Actual:   const mapboxToken = 'tu_token_aqui';
   ✅ Cambiar: const mapboxToken = 'pk.tu_token_de_mapbox';
   
   Obtener en: https://www.mapbox.com/ → Create account → Tokens

2. FIRESTORE RULES (Recomendado)
   Ver archivo: DELIVERY_SETUP.md
   
3. USUARIOS CON ROL "delivery"
   En Firebase Console → usuarios collection
   {
     "uid": "...",
     "email": "delivery@example.com",
     "displayName": "Juan García",
     "rol": "delivery"
   }

  → Crear pedido como cliente
